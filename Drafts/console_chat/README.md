# Консольный чат — учебный проект (OTUS, C# Professional)

Архитектура консольного чата, который реализует общение нескольких пользователей через терминал.
Проект использует принципы **DDD**, **микросервисную** архитектуру, **многопоточность** и базу данных.
Стек: **C# / .NET**.

## Ключевые решения

- **DDD** — доменная модель выделена в отдельные bounded-контексты (`Users`, `Chat`), агрегаты управляют инвариантами.
- **Микросервисы** — `ChatService` и `UserService` + `API Gateway`; обмен событиями через брокер (RabbitMQ).
- **Многопоточность** — асинхронная обработка команд, WebSocket-hub для push, фоновая обработка outbox и событий.
- **БД** — PostgreSQL; транзакции через Unit of Work, репозитории поверх EF Core.
- **Консольный клиент** — однопоточный UI на фоне асинхронного получения сообщений.
