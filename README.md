# BlackBox

## О проекте

BlackBox — консольный мессенджер для обмена сообщениями в реальном времени. Приложение работает непосредственно в терминале и поддерживает подключение нескольких пользователей к общему серверу.

Проект предназначен для общения без графического интерфейса, а также для изучения сетевого взаимодействия, клиент-серверной архитектуры и разработки приложений командной строки.
