# Функции и роли консольного чата

## 1. Роли пользователей

В чате вводится несколько ролей участников одного чата:

| Роль | Права |
|------|-------|
| **OWNER (владелец)** | Создаёт чат. Управляет участниками, назначает администраторов, удаляет чат. |
| **ADMIN (администратор)** | Добавляет/удаляет участников, меняет роли (кроме владельца), удаляет сообщения. |
| **MEMBER (участник)** | Читает сообщения, отправляет сообщения, выходит из чата. |
| **GUEST / гость (необязательно)** | Только чтение (см. «необязательные функции»). |

Глобальные роли системы (аутентификация):

| Роль | Назначение |
|------|-----------|
| **AuthenticatedUser** | Зарегистрированный пользователь — может создавать чаты и вступать в них. |
| **Anonymous** | Не зарегистрирован — только регистрация/вход. |

Логика ролей в границах одного чата соблюдается **доменной моделью** (инварианты агрегата `Chat`): нельзя удалить владельца, нельзя понизить владельца, администратор не удаляет администратора и т.д.

## 2. Список функций

### 2.1 Аутентификация и профиль (UserService)

| # | Функция | Приоритет |
|---|---------|-----------|
| A1 | Регистрация нового пользователя (имя пользователя + пароль) | Базовый |
| A2 | Вход (логин/пароль), выдача токена (JWT) | Базовый |
| A3 | Выход (logout), отзыв токена | Дополнительный |
| A4 | Просмотр и редактирование профиля (имя, аватар, «о себе») | Дополнительный |

### 2.2 Чат и сообщения (ChatService)

| # | Функция | Приоритет |
|---|---------|-----------|
| C1 | Создание чата (создатель становится OWNER) | Базовый |
| C2 | Вступление в чат по приглашению/id | Базовый |
| C3 | Выход из чата | Базовый |
| C4 | Отправка текстового сообщения | Базовый |
| C5 | Получение истории сообщений (постранично) | Базовый |
| C6 | Получение новых сообщений в реальном времени (push) | Дополнительный |
| C7 | Список участников чата | Дополнительный |
| C8 | Добавление/удаление участника (ADMIN/OWNER) | Дополнительный |
| C9 | Назначение ролей (ADMIN/OWNER) | Дополнительный |
| C10 | Удаление/редактирование сообщения | Дополнительный |
| C11 | Список чатов пользователя | Дополнительный |
| C12 | Чтение сообщений, индикатор «прочитано» | Дополнительный |

### 2.3 Система/инфраструктура

| # | Функция | Приоритет |

## 3. Базовые функции (минимум для работы)

Это то, без чего система **не может** выполнять самые базовые операции «создать чат и писать сообщения»:

- Регистрация и вход (A1, A2).
- Создание чата (C1).
- Отправка сообщения (C4).
- Получение истории сообщений (C5).
- Хранение данных в БД (S3, S4).

Всё остальное — расширяемость, которую можно добавить позже. Подробнее — в [MVР-архитектуре](./architecture_mvp.md).

## 4. Нефункциональные требования

- Многопоточность: обработка нескольких клиентов одновременно (асинхронный I/O, `async/await`).
- Масштабируемость: возможность добавления узлов служб без простоя.
- Надёжность доставки сообщений: outbox + подтверждение брокера.
- Безопасность: хэширование паролей (PBKDF2/Argon2), JWT.
- Консистентность: транзакции внутри сервиса (Unit of Work), сага/компенсация на границе сервисов (дополнительно).
